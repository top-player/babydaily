# 宝宝日常

**把日常过成一场养成游戏。**

宝宝日常是一款 Android 应用，把你想要坚持的事交给一个只属于你的主角：完成一项任务、打完一次卡、写下一段笔记，主角就会长一点经验、涨一点属性。它不催你、不排名、不发推送，只用等级、称号与连续记录，让长期坚持这件事变得看得见。

---

## 设计取向

- **一个主角，长期陪伴**：所有目标、习惯与记录都长在同一个角色身上，看到的是长期轨迹，而不是一堆互相孤立的清单。
- **成长只由行为决定**：经验值不可购买、不可手动调整，每一项行为的经验都是固定的。
- **惩罚克制，失败不羞辱**：属性有下限、不会变成负数；判失败只是归档，永远不会删除你写过的东西。
- **不联网，不打扰**：没有账号、没有排行榜、没有推送，数据只留在你自己的手机上。

## 功能

### 主角与成长

- 自建主角（姓名、年龄、性别，之后随时可改），主角页是成长总览：等级、称号、三项属性与场景。
- 经验值驱动等级，满级 50 级；升级时全屏反馈并解锁新称号，从「初出茅庐」一路到「人生赢家」。
- 三项属性：健康值、自律值、魅力值，各自 0–100，**不随时间衰减**——只有你做的事会让它们变化。
- 每天第一次打开应用（含从后台切回）+1 经验，主角页会标出当天已到账；没打开的日子不补发，也不惩罚。
- 首次启动有一小段新手引导，可以跳过。

### 任务

- **主线任务**：重要的长期目标，可以拆成子项逐步推进，最后一个子项完成时主线自动完成并发放奖励。
- **支线任务**：一次性的事，与主线一起常驻任务列表。
- **每日任务**：每天 0 点重置；完成 +1 经验，当天未完成会扣掉你为它配置的属性并记为失败，任务本身保留、次日照常。
- **判失败**：任何任务都可以手动标记失败。失败不删除任务、不扣属性：每日任务次日照常，主线/支线进入「已失败」归档。
- 奖励由你配置：完成一项任务或打完一次卡，加多少健康/自律/魅力都由你决定，经验由系统固定发放。
- 卡片可以逐张折叠，已完成 / 已失败归档可以整段收起；每日任务清空、连续打卡 7 / 30 / 100 天时会有庆祝反馈。
- 打卡、发奖与升级都带触感与浮层反馈，不需要盯着数字看。

### 每日任务页

入口在任务页，点开是独立页面：顶部是今天（可完成、可判失败），下方按日期上下滑动查看历史。完成与失败逐日留痕，即使之后删除了这个任务，历史记录依然在。

### 习惯

- 两种频率：**每日**，或**每周 N 次**。
- 打卡默认 +1 自律值、+5 经验，奖励可以按习惯单独配置；同一习惯每天只计一次。
- **连续记录**：每日习惯按天计算；每周 N 次习惯按自然周（周一至周日）是否达标计算。连续 10 / 20 / 30 天各发放一次里程碑奖励，每个习惯终身一次。
- 断签后连续天数归零（不提供补签），但累计打卡次数永久保留。
- 详情页用月历 + 年度热力图回看坚持情况；暂时不想做的习惯可以归档，之后随时恢复。

### 笔记

一天可以写多篇，按天翻页浏览，支持全文关键词搜索并直接跳到命中的那天。笔记只做记录，不发放经验——写给自己看的东西，不必变成任务。

### 场景

家里 / 公司 / 游玩三套氛围，手动切换后主题配色、问候语与提示文案一起变化。

### 备份与恢复

- **导出**：一键生成 JSON 快照，保存到手机「下载/BabyDaily」，包含主角、任务、每日任务历史、习惯、笔记与设置。
- **导入**：用系统文件选择器挑任意位置的备份文件即可恢复，换机或从电脑拷回来都能用。
- 数据只存在你的手机里，**定期导出是唯一可靠的保险**。

## 数值速查

### 经验来源

| 行为 | 经验 |
| --- | --- |
| 完成主线任务 | +50 |
| 完成支线任务 | +20 |
| 完成每日任务 | +1 |
| 习惯打卡 | +5 |
| 每天第一次打开应用 | +1 |
| 习惯连续 10 / 20 / 30 天 | +20 / +30 / +50（每个习惯各一次） |
| 完成主线子项 | 0（子项本身不发奖，主线完成时一起发） |
| 写笔记 | 0 |

### 属性

健康值、自律值、魅力值，新主角各 50，范围 0–100。奖励发放封顶 100，惩罚扣减下限 0，不会出现负数。

## 几条需要知道的规则

- **每日任务在 0 点结算**：当天没完成，会扣掉你为它配置的属性并记为失败。睡前记得处理。
- **登录经验不补发，习惯断签不补签**：奖励只对真实发生过的行为生效，这是刻意设计的。
- **判失败不可恢复，删除任务不会删除历史**：记录是你的，应用只负责留痕。
- **经验值不可购买、不可手动调整**，一切成长都来自你实际做的事。

## 系统要求与安装

- 系统：Android 7.0（API 24）及以上。
- 目前不提供官方安装包，需要从源码自行构建（Flutter 3.44 + Android SDK，分 ABI 的 release 包约 8–9MB）。步骤见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。

## 数据与隐私

- 全部数据保存在手机本地（应用私有目录的 SQLite 文件），不上传、不同步、不联网。
- release 包不申请网络权限；应用内没有账号体系，也没有统计、广告或崩溃上报 SDK。
- 唯一的数据出口是你手动导出的备份文件。
