# 本地 SQLite（drift）+ JSON 手动备份作为唯一持久化

宝宝日常 v1 是纯本地、单设备应用：所有数据（主角、任务、打卡、笔记）持久化在设备 SQLite 数据库（通过 drift 的类型化查询层访问），并提供 JSON 导出/导入作为换机与防灾备份，不做云同步。

**Considered Options**
- sqflite（手写 SQL）：可行，但查询无类型安全，表结构演变时易错。
- Hive / Isar（NoSQL 键值/文档库）：启动快、API 简单，但任务—子项—完成历史、习惯—打卡记录、笔记—日期索引天然是关系型数据，SQL 的查询与索引更直接。
- shared_preferences：只适合少量键值，无法承载三类业务数据。

**Consequences**
- 表结构变更需要 drift 迁移脚本，测试覆盖迁移。
- v2 若要云同步，可以时间戳为合并基础设计；JSON 导出格式即同步数据的基础形状。
