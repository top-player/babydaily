# 每日结算惩罚：未完成的每日任务扣除配置属性

每天 0 点，每日任务统一重置为未完成；当天未完成的任务，按其在奖励中配置的健康值/自律值/魅力值原数扣除。属性下限 0、不为负；经验值与等级永不扣除（等级只升不降）。惩罚只适用于「每日任务」类型——主线/支线常驻列表不受影响；习惯断签也不扣属性（断签归零本身就是代价）。任务卡片始终明示"未完成将 -N 属性"，让代价在发生前可见。v1 不提供暂停日（请假/旅行免扣）。

**Considered Options**
- 无惩罚（治愈系应用的常规做法）：被否——用户明确希望用对称的得失强化每日承诺。
- 未完成的任务顺延到次日：被否——任务会堆积，造成压力。
- 惩罚包括经验值：被否——等级倒退会打击长期积累，破坏"只进不退"的成长感。

**Consequences**
- 创建/编辑每日任务时，卡片与表单必须展示潜在扣除，避免用户无意中建出高惩罚任务。
- 属性下限 0 意味着连续多日未完成时惩罚自然停止，不会出现负数债务。
