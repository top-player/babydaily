# 笔记不发放经验：只做记录，不参与成长结算

笔记从经验来源中移除：写笔记（无论多少字、连续多少天）不再发经验，也不再改写任何属性。ADR-0003 的经验来源表里，笔记那一行作废；其余来源（主线 +50、支线 +20、习惯打卡 +5、里程碑）保持不变。

历史已经发放的笔记经验不回收——等级只升不降（ADR-0003），追回会打破这个承诺。

**Considered Options**
- 保留"≥20 字 +10、连续加成"（原设计）：被否——用户明确要求笔记不涨经验；而且"凑字数"的动机与"随手记录"的定位相冲突。
- 降额保留（如每篇 +2）：被否——仍会诱导为经验写字，且需要重新设计防止刷经验的按天标记。
- 只取消连续加成、保留基础经验：被否——用户要的是"不涨经验"，半保留仍会带来凑字数的动机。

**Consequences**
- 笔记模块不再有经验文案（写笔记对话框的提示、保存后的"经验 +N"浮层都已去掉），保存后靠列表里出现的新内容反馈。
- `note_xp.dart`、`noteStreakDays` 与 `noteBaseXp / noteStreakBonusCap` 常量删除；笔记的连续天数概念一并取消。
- 旧备份里可能残留 `note_xp_granted_on` 设置项，导入时原样保留，不再读写。
