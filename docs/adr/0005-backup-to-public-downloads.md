# 备份落到公共下载目录（MediaStore），数据库仍在应用私有目录

新安卓（Android 10+/MIUI/HyperOS）对存储收紧：应用文档目录（`Android/data/.../app_flutter`）对用户与文件管理器不可见，旧版"导出到应用内部目录 + 手动改名放置"的备份流程在小米手机上用户根本找不到文件。因此备份文件改为通过 MediaStore 写入公共下载目录「下载/BabyDaily」，导入也从该目录列出并选择备份；Android 9 及以下回退公共 Download 目录（`WRITE_EXTERNAL_STORAGE` 仅限 maxSdkVersion 28），通道不可用时再回退应用文档目录。

数据库（SQLite，ADR-0001）仍是应用私有数据，继续存于应用文档目录，不进入公共目录。

**Considered Options**
- 保持应用内部目录：不需要权限，但用户在文件管理器里找不到备份，换机体验断裂。
- 系统分享面板（share_plus 等）：一步到位可发微信/网盘，但引入新插件依赖，"存了一份在手机里"的诉求仍要二次操作。
- 公共下载目录 + 自研极简 MethodChannel：无需新依赖，可控；导入只能读取本应用导出的文件（第三方文件需系统授权，界面会标注"无法读取"），USB 拷入的备份需走高级路径（应用文档目录）。**（导入部分已由 ADR-0008 改用系统文件选择器取代）**

**Consequences**
- 备份文件对用户可见：小米文件管理 → 下载 → BabyDaily。
- 导入提供文件选择列表（时间倒序），并保留"应用内部目录"高级入口向后兼容。
- 旧设备（API < 29）与通道异常时自动回退旧行为，导出/导入不因新系统而报错。
- 2026-09 修订（ADR-0008）：导入改为系统文件选择器（SAF）——自列目录在 Android 11+ 只能看到本应用写入的文件，换机/电脑拷回的备份会"识别不到"。导出侧仍写公共下载目录。
