# 经验值经济：固定来源、不可配置、满级 50

经验值的发放数值完全由系统固定，用户不能为任务或习惯配置经验值奖励；任务与习惯的「奖励」配置只包含健康值、自律值、魅力值三项。主角满级 50 级；满级后经验继续累计展示（等级停留为"满级"）。

## 经验来源（固定）

| 来源 | 经验 |
| --- | --- |
| 主线任务完成（含全部子项完成后的自动完成） | +50 |
| 支线任务完成 | +20 |
| 任务子项完成 | 0 |
| 每日任务完成 | 0（只有属性奖励；未完成按 ADR-0004 扣属性） |
| 习惯打卡（每日习惯与每周 N 次习惯相同，每天每习惯最多 1 次） | +5 |
| 每日习惯连续里程碑（按每个习惯独立、终身各一次） | 连续 10 天 +20、20 天 +30、30 天 +50 |
| 笔记 | 0（2026-09 修订：笔记不再发放经验，见 ADR-0006） |

## 等级曲线

| 等级区间 | 升到下一级所需经验 nextExp |
| --- | --- |
| Lv 1–9 | 40 + (Lv−1) × 3 |
| Lv 10–29 | 70 + (Lv−10) × 4 |
| Lv 30–49 | 110 + (Lv−30) × 6 |
| Lv 50 | 满级（用户提供的 Lv50+ 公式保留备用，封顶后不使用） |

## 称号（纯装饰）

Lv1 初出茅庐 · Lv5 小有所成 · Lv10 持之以恒 · Lv15 自律新星 · Lv20 自律达人 · Lv30 自律大师 · Lv40 生活冠军 · Lv50 人生赢家

**Considered Options**
- 奖励里可配置经验值（原始需求）：被否——用户可通过创建"奖励拉满的琐碎任务"刷经验，经济失衡；固定来源让每种行为的价值由系统定义，也更符合"轻松治愈"的预期。
- 不设等级上限：被否——满级 50 给长期使用一个终点，也避免曲线无限膨胀。

**Consequences**
- 任务/习惯的奖励表单只有三属性，不出现经验字段。
- 需要按习惯记录已领取的里程碑（10/20/30 天各一次），防止重复发放；打卡日志本身足以支撑该计算。
- 满级后 XP 仍累计，为未来扩展（如满级后内容）保留数据。
- 2026-09 修订：笔记一项归零（ADR-0006），原先为笔记设计的"按天发放标记"与连续加成随之删除。
